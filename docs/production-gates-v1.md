# Stage gates v0.1
1. Knowledge: evidence IDs, model/plant variant, conservation principles, missing-data register; uncertain facts BLOCKED.
Current still-frame authority: docs/production/keyframes-v1/. SVG is optional, direct high-quality PNG mandatory. These operational lists do not define an alternative image status or delivery contract; use alignment.md for state mapping and the per-shot double-review records.
2. Script: factual reviewer approves text and visual claim list; do not imply unverified thermodynamic flow.
3. Keyframes: approved source geometry, equipment ID registry, consistent color and camera rules. Images must be reviewed. A prompt/ControlNet cannot prove engineering correctness.
4. Clips: compare selected frames against approved keyframes; detect morphing, missing components and flow reversal. If inference unstable, deterministic 2D/3D animation is preferred.
5. Assembly: optional manual step. Caption narration is independent of silent clip generation.
State meanings: DRAFT editable, REVIEW awaiting human gate, APPROVED downstream allowed, LOCKED immutable snapshot; BLOCKED applies to unstarted dependent artifacts.
Machine validation checks syntax and prerequisites ONLY, never claims industrial fact correctness.
