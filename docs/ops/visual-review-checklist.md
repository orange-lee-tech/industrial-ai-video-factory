# Pilot art-to-clip gate (B+ toward C)
Work's existing geometry SVG is the **engineering source**, not automatically final art. User's `Surface Condenser` reference is a **visual quality** reference only, and its ambiguous arrows are not engineering authority.

### Before any paid render
- [ ] Source-verified claim ledger complete and reviewed for each visual statement.
- [ ] SH007 condenser shell, tube bundles, tube sheets, waterboxes and hotwell identified with stable geometry IDs and version.
- [ ] SH007 full-resolution art frame reviewed at target 16:9: shape hierarchy, contrast, readable negative space, visual polish, compositional unity, 2.5D depth with no invented piping.
- [ ] Labels and narration absent from raw visual frame; generated textual labels may not be trusted.
- [ ] Avoid excessive blanket glow, full-screen callouts or motion that obscures cooling-water tube boundary.
- [ ] Pair-review visual continuity with neighbors; reference SHA recorded.
- [ ] 6-second clip dry-run/preview and frame checks for entry/mid/exit, visible but motivated motion and end pose hold. Static equipment does **not** float merely to pass a motion metric.
- [ ] ffprobe actual duration/codec/fps; compare visual versus approved art.
- [ ] User signs off *quality* separately from technical factual reviewer; render approval is not signoff on industrial correctness.

### Reference implementation QA labels
`UNVERIFIED` / `NEEDS_REVIEW` / `ACCEPTED` / `REJECTED`; do not assign ACCEPTED from automated still-size or file-existence checks.
