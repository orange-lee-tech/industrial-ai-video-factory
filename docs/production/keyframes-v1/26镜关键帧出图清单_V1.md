## 总则

- 事实源：经审查批准的**逐镜分镜脚本**；对工业结构另以可靠厂家/教材资料约束。先脚本，后出图；不再要求每镜制作 SVG。
- 成片视觉目标：B+ 工业科普 2D / 2.5D，未来逐镜升级 C。照片级精度不是硬指标，但构图、层次、材质与信息表达必须达到可入片水平。
- 全片 16:9 / 1920×1080、25×6秒+8秒片尾；第一批优先 SH003、SH007–SH011；SH007 作为风格批准样张。
- 生成图不含中文标签、标题、字幕、示意箭头；这些交由确定性后期。**背景图可以隐含物理流体与设备材质，不可自行画出错误标注。**
- 硬约束：冷却水在管内、汽轮机排汽在壳侧管外、凝结水汇热井、抽气支路独立；当前示意图为典型方案，不冒充特定机组实际施工图。
- 每镜交付 `SH###_keyframe.png`（真实成片级图像）、`SH###_brief.md`、`SH###_prompt.txt`，保存源图来源/模型参数与审核状态。SVG 是可选辅助，不计作最终 PNG。
- 镜头间同一设备 ID、镜头方向、颜色语义和结构应保持一致；不同镜头可以采取全景、局部、微观、比较等视觉语言，不得一张图平移复制 26 次。
- 未通过“知识核查+视觉验收”的分镜**不得批量图生视频**，不擅自产生费用。
