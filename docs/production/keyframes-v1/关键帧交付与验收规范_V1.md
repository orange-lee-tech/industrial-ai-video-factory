# 镜头关键帧交付与验收规范 V1.0

## 优先级
1. 逐镜叙事准确且专业事实有依据；2. 成片级 PNG 画质与可读性；3. 连续性；4. 动画可行性与成本。**SVG、参数文件、脚本数量不得替代图片质量。**

## 生产状态
`SPEC_READY -> IMAGE_DRAFT -> FACT_REVIEW -> ART_REVIEW -> APPROVED -> MOTION_READY`。`APPROVED` 必须有事实审查者及视觉审查者两项明确记录，机器检测只证明尺寸、文件路径与格式，不能替代人审。

## 每镜输入契约
- 来源版本：分镜脚本 SHA/版本、shot_id、精确时间、旁白、视觉目标。
- 事实约束：工程参考资料、设备编号、不可改变的空间关系、待核事项。
- 风格：统一 B+ 调色、空间层次与材质，必要的图像参考；不强制每镜复用同一画面。
- 镜头：近景/全景、主体位置、后期文字安全区域、与相邻镜头承接。

## 每镜输出契约
- `SH###_keyframe.png`（16:9，优先 1920×1080）；可附 `SH###_keyframe.webp` 分发版本。
- `SH###_brief.md`：镜头目的、构图、必须/禁止元素、验收争议、衔接。
- `SH###_prompt.txt`：最终实际使用提示词与负面约束（若使用生成模型）。
- `SH###_provenance.json`：模型/版本、参考文件哈希、出图时间/参数、费用、结果文件 SHA256、审核人/意见。
- 有图层要求时可额外交付透明分层；**不可用低质量 SVG 强制替代 PNG**。

## 实物验收
- [ ] 文件真实存在，可正常打开，宽高比16:9，无明显压缩瑕疵/错字/水印。
- [ ] 旁白对应的**这一镜**可以被观众读懂；无无关元素抢戏。
- [ ] 工业关系未出现错接、混流、倒流、额外虚构设备；特殊构型有依据。
- [ ] 设备比例、结构逻辑、颜色意义在相邻镜头保持一致。
- [ ] 观感不低于此前批准的 SH007 PNG 质量基准，而不是现有简陋 SVG 草图。
- [ ] 画面下部给未来字幕留安全区；生成图不生成文字，后期可编辑叠加。
- [ ] 能明确指出以后要怎么动：可缓推、分层高亮、局部动画或另行生成视频；不需要虚假运动。
- [ ] 凝汽器微观/全景/回路比较镜头有明显构图差别。

## 成本止损与批次
先 SH007 作为风格锚点；首批再产 SH003、SH008–SH011。首批人工验收前不生成剩余20镜，不跑收费图生视频。一次只改失败约束，保留上一版 PNG 与失败原因，避免原样重试。根据质量决定是使用生成式图像、示意图叠加还是其他方式，不预设唯一模型。

## 与 GitHub 的关系
规范可进入 main。真实源图、关键帧、视频和大文件放在受控统一工作区，通过 manifest/哈希交接；GitHub 不作为素材生产服务器。用户分享的视觉参考图不能自动取代可靠工程资料。
