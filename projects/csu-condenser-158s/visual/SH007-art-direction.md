# SH007 成片级样板说明

当前：一张真实生成的高完成度2.5D美术候选图，状态VISUAL_REVIEW。没有动画预览，没有批准，也没有批量推进其他镜头。原工程母版保留不变。

## 画面构图

固定正视纵剖面，浅景深与金属厚度营造2.5D层次。设备居中横贯画面，视觉顺序为顶部蒸汽入口、中央管束、底部热井；两端管板以较厚银色纵向边界区分水室与壳侧。明亮暖白背景与接触阴影提升辨识度，减少旧图大面积深色背景带来的压缩感。

这张样板先确定设备美术风格，不把暗部、材质或镜头光影当作新工程结构。后续正片以1920×1080建立外部画布，图像等比缩放至画幅约82%宽，左右各留9%供标签；上方约12%用于标题/结构标注，下方约12%用于字幕。当前原图仍为两侧管路通出画面、设备占比偏大的构图，不声称上述外部排版已经完成。不得靠拉伸图片匹配16:9。

## 配色规则

| 对象 | 固定语义色 | 表现方式 |
| --- | --- | --- |
| 金属壳体、管壁、管板 | 银灰 #9CAAB7，切面深灰 #344756 | 拉丝、倒角、高光与接触阴影；金属不发光、不变形 |
| 管内冷却水、水室 | 深蓝 #1677C8，明部 #43C8FF | 同一蓝色语义，只在管内和水室；不当温度刻度 |
| 壳侧水蒸气 | 淡青 #BFEFF5 | 非写实的轻透明提示；最终应减弱云雾，不作为烟尘或液体 |
| 凝结水、热井 | 琥珀金 #E8B54A | 仅在管外汇流及底部收集区；高光不能演成沸腾 |
| 不凝结气体 | 中性灰 #A6AFBA | SH007不展示抽气支路；在专门镜头再增加独立符号 |
| 背景、文字 | 暖白 #F5F6F4，文字深蓝灰 #183247 | 清晰高对比；不使用亮霓虹字 |

图中颜色是介质编码，不暗示实际水颜色、压力或温度。材质可以变化明暗，但不得让语义色互换。样板中水面与雾气纹理偏强，后续素材拆层时需抑制；当前静图不用于证明液位或流态。

## 标注规则

所有标注与图像分离，不由图像模型写字。SH007一次只强调壳体、管束、管板、水室；蒸汽入口和热井可作为弱标注，避免把后续镜头的介质原理全堆在同一画面。

1080p时主标题40px、结构标签30px、旁白字幕36px，采用Noto Sans CJK SC或可替代的清晰无衬线字体。标签在设备外，文字不压管壁；单条细折线连接一个对象，端点落在正确边界，线宽约2px。管板标注指向两端的纵向分隔板，不指向侧面端盖；水室指向蓝色腔体，不指向金属法兰。中文为主，英文仅作为可选辅助。

抽气管在本镜头不显示，所以不能给水室底部加“抽气口”标签。禁止照搬用户参考图中含混接口文字。叠加文件需要再次视觉检查，不能仅凭坐标存在宣布标签正确。

## 动画空间设计

| 时间 | 动作设计 | 约束 |
| --- | --- | --- |
| 0.0–1.2s | 同轴全景承接SH003，保持约0.3s清楚停留 | 不环绕、翻转或改变管束 |
| 1.2–2.4s | 壳体边缘轻描边，标签出现 | 只动高亮层；金属不呼吸变形 |
| 2.4–3.8s | 管束整体轻高亮 | 不让管束位移或膨胀；此镜不详演流体 |
| 3.8–5.1s | 两端管板、水室依次引线 | 管板密封边界固定，蓝水不能串入壳侧 |
| 5.1–6.0s | 保持完整结构图，标签降到稳定态，承接SH008 | 留末尾0.3s剪辑稳定区，不新增设备 |

以上是空间与节奏设计，尚未执行。当前PNG是一张展平的美术图，不能声称已拆出金属、蒸汽、液膜、流向的独立图层。样板获确认后才制作：设备底图、固定结构遮罩、介质/高亮层、标签引线层、字幕层。若仅做轻推近，可用底图和独立标签；若需要管内外流动或剖面变化，必须先制作审核过的区域遮罩/可编辑场景，不能用全图扭曲假装流体动画。
